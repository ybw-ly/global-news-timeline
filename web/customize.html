翻译接口

选中哪个接口，手动翻译和浏览自动翻译就用哪个；付费接口按量计费。

说明

  • API Key 只保存在本机 data/customization.json；读取接口只返回“是否已保存”，默认导出会移除所有密钥。
  • “自动”只是免费链：LibreTranslate → MyMemory → Ollama；选其他接口就固定用那个接口，失败会直接提示。
  • 付费接口没有额外的“仅免费/回退”开关；选中即使用，请自行确认服务商计费。
  • 公开部署时请设置 ADMIN_TOKEN 或用反向代理限制 /api/translate，避免他人消耗你的付费额度。
